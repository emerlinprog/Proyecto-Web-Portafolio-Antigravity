POLÍTICA DE PRIVACIDAD v2.1

Gobernanza
de Datos.

Esta plataforma recopila la información que compartes voluntariamente al utilizar formularios de diagnóstico, asistentes de IA (Discovery Wizard), listas de espera o herramientas de validación operativa. Esta información se utiliza exclusivamente para responder solicitudes, medir el uso de activos digitales y optimizar los recursos de consultoría estratégica disponibles.

security Seguridad Agéntica

Las herramientas impulsadas por Inteligencia Artificial pueden registrar metadatos técnicos, estados de cuota y eventos de orquestación para prevenir el abuso y garantizar la disponibilidad del sistema. No publicamos ni comercializamos estos datos bajo ninguna circunstancia.

Toda la infraestructura de backend, incluyendo claves de API y procesamiento de modelos (Anthropic, Groq), se ejecuta en entorno servidor seguro. La integración con servicios de terceros (Notion, Netlify) se limita estrictamente a la información necesaria para ejecutar la función solicitada por el usuario.

Usted mantiene el derecho a solicitar la revisión o eliminación total de sus datos personales enviando una solicitud mediante el formulario de Contacto Principal.
